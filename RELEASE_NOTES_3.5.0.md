# VoiceCapture 3.5.0

## Список дел голосом и плавающая шайба

- Зажмите обычный хоткей записи и дополнительно **⇧ Shift** — распознанный текст добавится в список дел вместо вставки.
- В оверлее записи появляется зелёный бейдж `📝`.
- Полупрозрачная шайба находится поверх окон и на всех рабочих столах. При наведении раскрывается в список текущих дел.
- Шайбу или раскрытый список можно перетащить; позиция сохраняется.
- Галочка зачеркивает задачу. Через **5 секунд** она удаляется; снятие галочки в течение этого времени отменяет удаление.
- Текст задачи можно редактировать: Enter сохраняет, Esc отменяет.
- Функция включается и выключается в **Настройки… → Список дел (⇧ + хоткей записи)**. Выключение скрывает шайбу и отключает режим задач, но не удаляет уже сохранённые задачи.

Задачи хранятся локально в `~/Library/Application Support/VoiceCapture/todos.json`.

## Перевод Apple Translation

Удерживайте обычный хоткей вместе с **⌥ Option**. Речь переводится локальным Apple Translation. Целевой язык выбирается в **Настройки… → Перевод (⌥)**. Перевод требует macOS 15+.

## Настройки

- `todoEnabled`: включает список дел и шайбу;
- `autoPaste`: автоматически вставляет распознанный результат через Cmd+V;
- `backend`: `local` | `fluidAudio` | `groq` | `both`;
- `localModel`, `language`, `initialPrompt`;
- `groqApiKey`, `groqModel`;
- `microphoneUID`;
- `translationTarget`;
- `localStartDelay` для режима `both`.

`⌥` зарезервирован под перевод, `⇧` — под список дел и не назначаются в основной хоткей.

## Быстрый старт

1. Запустите `VoiceCapture.app`.
2. Предоставьте доступ к микрофону и Accessibility / Универсальному доступу.
3. Выберите движок и модель в **Настройки…**.
4. Для обычной диктовки зажмите `⌘⌃`.
5. Для задачи зажмите `⌘⌃⇧`.

## Сборка

Для сборки нужен Xcode toolchain:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./build_app.sh
open dist/VoiceCapture.app
```

CommandLineTools могут завершиться ошибкой `plugin for module 'SwiftUIMacros' not found`; используй команду выше с `DEVELOPER_DIR`.

Модели скачиваются отдельно и в репозиторий не включаются. Старый Python/PyQt6-проект находится в соседней папке `../voice2.0` и не относится к этому приложению.

## Лицензии

Проект использует whisper.cpp и FluidAudio согласно их лицензиям. Apple Translation является системным API macOS.

## Выпуск 3.5.0

Новая функция списка дел с локальным JSON-хранилищем, плавающим виджетом, голосовым добавлением задач, редактированием и безопасным удалением с 5-секундной отменой.

## Выпуск 3.4.0

Добавлен локальный перевод через Apple Translation с выбором языка и автоматической загрузкой языковых пакетов macOS.
