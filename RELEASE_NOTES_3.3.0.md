## Главное

VoiceCapture 3.3.0 добавляет выбор микрофона прямо в настройках приложения. Больше не нужно менять устройство ввода в системных настройках macOS: VoiceCapture может писать с конкретного микрофона независимо от системного выбора.

## Что изменилось

- В окне настроек появился выпадающий список **«Микрофон»** со всеми устройствами ввода системы.
- Первый пункт — **системный микрофон по умолчанию**, его текущее имя показано в скобках.
- Выбранное устройство сохраняется в `settings.json` по CoreAudio UID (`microphoneUID`) и переживает перезапуск.
- Смена микрофона применяется сразу после **Сохранить**, перезапуск приложения не нужен.
- Если сохранённое устройство отключили (например, вынули USB-микрофон), приложение автоматически возвращается к системному по умолчанию.
- При старте записи в лог пишется выбранное устройство: `[Audio] Микрофон: <имя>`.
- Внутренне `AVAudioEngine` пересоздаётся на каждую запись — это устраняет залипание старого формата входа при смене устройства.

## Установка

1. Скачай и распакуй `VoiceCapture-3.3.0-macOS-arm64.zip`.
2. Перетащи `VoiceCapture.app` в `/Applications`, заменив предыдущую версию.
3. Если macOS блокирует запуск, сними карантин:

```bash
xattr -dr com.apple.quarantine /Applications/VoiceCapture.app
```

4. Запусти приложение. Существующие настройки и скачанные модели сохранятся.

## Требования

- Apple Silicon (M1 или новее);
- macOS 14 Sonoma или новее;
- разрешения Microphone и Accessibility.

## Приватность

FluidAudio / NVIDIA Parakeet TDT v3 работает локально через Core ML и Apple Neural Engine. Речь и live-транскрипт не отправляются в облако.
