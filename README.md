# VoiceCapture 3.6.0

Нативное menu bar-приложение на **Swift + AppKit** для голосового ввода в macOS: зажимаешь выбранный хоткей (по умолчанию **⌘ + ⌃**), говоришь, отпускаешь — готовый текст вставляется в активное приложение.

Добавь к хоткею **⌥** — получишь перевод через локальный Apple Translation. Добавь **⇧** — распознанная фраза попадёт в текущий список дел вместо вставки.

Главные возможности:

- hold-to-talk с глобальным хоткеем;
- локальные Whisper, NVIDIA Parakeet TDT v3, GigaAM v3 E2E RNNT и облачный Groq;
- live-текст во время записи в режимах FluidAudio и GigaAM;
- Apple Translation без облачных API;
- текущий список дел с плавающей шайбой поверх окон.

## Что нового в 3.6.0

- **GigaAM v3 E2E RNNT** — дополнительный локальный движок русского распознавания со встроенной пунктуацией, регистром и нормализацией текста. Без Python, API-ключей и LLM-корректора.
- Выбор и скачивание модели (~425 MB) в настройках. Требуется **Apple Silicon + macOS 15+**; прежние движки продолжают работать на macOS 14.
- Длинная диктовка без искусственного лимита 25/30 секунд: внутренние фрагменты по паузам, контекстное перекрытие и объединение целых слов по времени. Если VAD недоступен, используется деление по энергии без удаления аудио.
- Предварительный текст обновляется во время записи, окончательный проход — после отпускания хоткея. Работают обычная вставка, перевод через ⌥ и список дел через ⇧.

### Как попробовать GigaAM

1. Открой **Настройки… → Распознавание → GigaAM v3 E2E RNNT (русский — live)**.
2. Нажми **Скачать**, дождись компиляции модели, затем **Сохранить**.
3. Диктуй обычным хоткеем. Для сравнения переключись обратно на **FluidAudio (Parakeet v3 — live)**.

Распознавание локальное; интернет нужен для первой загрузки GigaAM и вспомогательной Silero VAD. GigaAM хранится в подпапке `gigaam-v3-e2e-rnnt` каталога моделей VoiceCapture. Язык и Whisper prompt на неё не влияют.

Используется [сторонняя Core ML-конвертация smkrv](https://huggingface.co/smkrv/gigaam-v3-e2e-rnnt-coreml) официальной [GigaAM](https://github.com/salute-developers/GigaAM), MIT, на CPU + GPU. Версия артефактов закреплена. Модели и личные настройки не включены в ZIP приложения.

**Ограничения:** GigaAM рассчитана на русский язык; пунктуация и слова на стыках могут ошибаться. Live — повторные проходы, не настоящий streaming; на длинной записи частота обновлений зависит от длительности и нагрузки. Предварительный текст может отличаться от итогового. Нет гарантии превосходства над Parakeet на конкретном голосе.

Проверено на синтезированной русской речи: 187 секунд с 12 контрольными пунктами и сохранённым концом записи, а также 118 секунд непрерывного текста без заданных пауз. Это техническая проверка, не пользовательская проверка микрофона или сравнительный WER-бенчмарк.

Для локальной обработки файлов без микрофона и автовставки:

```bash
.build/release/VoiceCapture --gigaam-download
.build/release/VoiceCapture --gigaam-file /path/to/audio.wav
```

## Что нового в 3.5.1

- Добавлен обход проблемы с буквой **«ё»** в FluidAudio / Parakeet TDT v3: служебный маркер `<unk>` заменяется на «ё»/«Ё» в live-тексте и итоговой диктовке. Например: «Ч<unk>-то» → «Чё-то».
- Это эвристика: `<unk>` означает неизвестный токен, а не исключительно «ё». В других языках или для иных отсутствующих символов замена может быть ошибочной. Whisper и Groq не затронуты.
- В релиз также входят все возможности 3.5.0: голосовой список дел и плавающая шайба.

## Что нового в 3.5.0

- **Текущий список дел голосом.** Зажми обычный хоткей записи и дополнительно **⇧ Shift** — распознанный текст попадёт в список дел вместо вставки в активное приложение. В оверлее появляется зелёный бейдж `📝`.
- **Плавающая шайба** поверх окон: при наведении показывает текущие дела. Список можно перетаскивать; позиция шайбы сохраняется.
- Галочка зачеркивает задачу и удаляет её через **5 секунд**. В течение этого времени галочку можно снять и отменить удаление. Текст задачи редактируется по клику, Enter сохраняет, Esc отменяет.
- В настройках появился переключатель **«Список дел (⇧ + хоткей записи)»**. Выключение скрывает шайбу и отключает режим задач; включение применяется после сохранения.
- `⇧` зарезервирован под список дел и больше не назначается модификатором основного хоткея.

## Что нового в 3.4.0

- **Перевод на лету через Apple Translation.** Зажми хоткей вместе с **⌥** — русская речь распознаётся и сразу переводится локальным движком Apple.
- В оверлее вместо красного индикатора появляется бейдж целевого языка (`EN`, `DE`, `UK`…).
- Новая настройка **«Перевод (⌥)»**: 12 языков.
- Перевод требует **macOS 15+**. На macOS 14 приложение работает без перевода.
- `⌥` зарезервирован под перевод и не назначается модификатором основного хоткея.

## Быстрый старт

1. Собери приложение или скачай [готовый релиз](https://github.com/oiv-an/voice-capture-mac/releases/latest). Готовая сборка рассчитана на Apple Silicon и macOS 14+; перевод требует macOS 15+.
2. Запусти `VoiceCapture.app`.
3. Предоставь доступ к микрофону и Accessibility / Универсальному доступу.
4. Выбери движок в **Настройки…**, скачай нужную локальную модель.
5. Зажми `⌘⌃`, продиктуй текст и отпусти — он вставится в активное приложение.

## Список дел

1. Включи **Настройки… → Список дел (⇧ + хоткей записи)** и сохрани. Шайба появится поверх окон.
2. Зажми основной хоткей записи и дополнительно `⇧`, продиктуй задачу и отпусти клавиши.
3. Наведи мышь на шайбу, чтобы открыть список. Перетащи шайбу в удобное место — оно сохранится.
4. Отметь задачу: она будет зачёркнута ещё 5 секунд. Сними галочку в этот момент, чтобы отменить удаление.
5. Нажми на текст задачи для редактирования; `Enter` сохраняет, `Esc` отменяет.

Настройка выключает и шайбу, и режим добавления задач. Уже сохранённые задачи не удаляются и снова появятся при включении функции.

Задачи хранятся локально в:

```text
~/Library/Application Support/VoiceCapture/todos.json
```

## Перевод Apple Translation

1. Выбери язык в **Настройки… → Перевод (⌥)**.
2. Зажми обычный хоткей записи и дополнительно `⌥`.
3. Говори по-русски и отпусти клавиши.

Перевод выполняется локально. При первом переводе macOS может предложить скачать языковой пакет.

## Настройки

Файл настроек:

```text
~/Library/Application Support/VoiceCapture/settings.json
```

Основные параметры:

- `backend`: `local` | `fluidAudio` | `gigaAM` | `groq` | `both`;
- `localModel`: файл выбранной Whisper-модели;
- `language`: `ru` | `en` | `auto`;
- `initialPrompt`: prompt для Whisper/Groq;
- `groqApiKey`, `groqModel`;
- `autoPaste`;
- `todoEnabled`: включает шайбу и добавление задач через `⇧` вместе с хоткеем;
- `microphoneUID`: CoreAudio UID выбранного микрофона;
- `hotkeyRequiresCommand/Control/Option/Shift`: модификаторы hold-to-talk хоткея;
- `translationTarget`: целевой язык перевода;
- `localStartDelay` для совместного режима.

### Переназначение хоткея

1. Открой **Настройки…**.
2. В строке **«Хоткей записи»** нажми **«Изменить»**.
3. Зажми нужную комбинацию из `⌘` и `⌃` и отпусти.
4. Нажми **«Сохранить»**.

`⌥` зарезервирован под перевод, `⇧` — под список дел и в основной хоткей не назначаются.

Whisper-модель можно скачать из настроек или скриптом:

```bash

```

Доступны `tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo`.

## Сборка из исходников

Для сборки нужен Xcode toolchain:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./build_app.sh
open dist/VoiceCapture.app
```

Обычный CommandLineTools может завершиться ошибкой `plugin for module 'SwiftUIMacros' not found`; в этом случае используй `DEVELOPER_DIR`, как в команде выше.

## Разрешения macOS

- **Микрофон** — нужен для записи.
- **Accessibility / Универсальный доступ** — нужен для глобального хоткея и авто-вставки.

После пересборки macOS иногда требует выключить и снова включить VoiceCapture в списке Accessibility.

## Диагностика

### Хоткей не работает

Проверь комбинацию в **Настройки… → Хоткей записи**, разрешение Accessibility и перезапусти приложение.

### Список дел не работает

Проверь, что включён пункт **Настройки… → Список дел (⇧ + хоткей записи)**. Для добавления задачи удерживай `⇧` вместе с основным хоткеем до конца записи.

### Авто-вставка не работает

Проверь Accessibility. Распознанный текст всё равно остаётся в буфере обмена и истории.

### Перевод не работает

Нужна macOS 15.0 или новее. Удерживай `⌥` вместе с основным хоткеем до самого отпускания.
