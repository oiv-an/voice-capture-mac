# VoiceCapture 3.8.0 — автообновление

## Новое

- **Приложение обновляется само.** Раз в сутки VoiceCapture проверяет последний релиз на GitHub. Если есть новая версия, открывается окно «Доступна новая версия» с описанием изменений.
- Кнопка **«Обновить и перезапустить»**: приложение скачивает новую версию, проверяет её, закрывается, заменяет себя на новую версию на том же месте и запускается снова. Перетаскивать в «Программы» и закрывать старую версию вручную больше не нужно.
- **«Позже»** закрывает окно; в меню остаётся пункт «⬆︎ Доступно обновление …». **«Пропустить версию»** — больше не напоминать об этой версии.
- В меню появился пункт **«Проверить обновления…»** для проверки в любой момент.
- Модели, настройки, история и список дел при обновлении не затрагиваются.

## Ограничения

- Версии до 3.7.2 включительно не умеют обновляться сами: 3.8.0 нужно один раз установить вручную. Все последующие версии придут автоматически.
- Если папка с приложением недоступна для записи, окно предложит скачать релиз вручную.
- После обновления macOS может один раз заново запросить доступ к микрофону или «Универсальному доступу».

## Установка

Скачать [VoiceCapture 3.8.0 для Apple Silicon](https://github.com/oiv-an/voice-capture-mac/releases/download/v3.8.0/VoiceCapture-3.8.0-macOS-arm64.zip), распаковать, перенести в «Программы» (закрыв старую версию) и запустить. Дальше обновления придут сами.
