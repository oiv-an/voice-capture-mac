# VoiceCapture 3.6.0 — GigaAM v3 E2E RNNT

## Новый локальный движок

- GigaAM v3 E2E RNNT для русского языка со встроенными пунктуацией, регистром и нормализацией текста.
- Нативный Core ML, CPU + GPU; без Python, API-ключей и внешнего корректора.
- Отдельный пункт в настройках, скачивание ~425 MB и локальная компиляция. NVIDIA Parakeet, Whisper и Groq сохранены для переключения и сравнения.
- Модель устанавливается через временный каталог: незавершённая загрузка не заменяет рабочую установку.

## Длинная диктовка

- Нет искусственного лимита общей записи в 25/30 секунд.
- Внутренняя сегментация по Silero VAD/паузам; резервный поиск границ по энергии, если VAD недоступен. Аудио не отбрасывается по решению VAD.
- Контекстное перекрытие и распределение целых слов по времени уменьшают дефекты стыков.
- Live-preview во время записи и отдельный финальный проход. Таймаут финального распознавания зависит от длины записи, поздний результат отменённой задачи не вставляется.
- Сохраняются обычная автовставка, перевод через ⌥ и список дел через ⇧.

## Требования и запуск

GigaAM требует **Apple Silicon и macOS 15+**. Прежние движки остаются доступны на macOS 14.

**Настройки → Распознавание → GigaAM v3 E2E RNNT → Скачать → Сохранить.** Если модель уже установлена, повторно скачивать её не нужно.

Интернет нужен для загрузки весов и вспомогательной VAD; распознавание выполняется локально. В ZIP нет моделей, ключей и пользовательских настроек.

Добавлены команды обработки аудиофайла и установки модели без запуска интерфейса: `--gigaam-file <путь>` и `--gigaam-download`.

## Проверка и ограничения

Проведены ручные технические проверки на синтезированной русской речи:

- 13.42 с: распознан текст с пунктуацией и «ё».
- 187.27 с: сохранены все 12 контрольных пунктов, начало и последняя контрольная фраза; первый проход занял 11.30 с с подготовкой моделей.
- 118.06 с непрерывной речи: после исправления стыка слова результат получен за 3.45 с на машине разработки с прогретыми системными кэшами.

Это не сравнительный бенчмарк и не проверка микрофона пользователя. Качество, пунктуация и слова на стыках могут отличаться на другой речи. Live-preview выполняет повторные проходы, не является настоящим streaming и может обновляться медленнее на длинных записях. Предварительный и итоговый текст могут различаться.
