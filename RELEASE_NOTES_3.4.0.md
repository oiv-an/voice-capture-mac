# VoiceCapture 3.4.0

## Перевод на лету через Apple Translation

Главная фича релиза: диктуете по-русски — получаете текст на выбранном языке.
Перевод выполняется локально движком Apple Translation, без внешних API и без
отправки текста в облако.

### Как пользоваться

1. Зажмите обычный хоткей записи (по умолчанию ⌘⌃) **и дополнительно ⌥**.
2. Говорите по-русски. В оверлее вместо красного индикатора появляется бейдж
   целевого языка (`EN`, `DE`, `UK`…). Отпустили ⌥ — бейдж исчез, перевода не будет.
3. Отпустите клавиши: текст распознаётся, переводится и вставляется как обычно.

Без ⌥ всё работает по-старому — чистая русская диктовка.

### Настройки

- Новый пункт **«Перевод (⌥)»** — выбор целевого языка.
- Доступно 12 языков: English, Deutsch, Español, Français, Italiano, Português,
  Polski, Українська, Türkçe, 中文, 日本語, 한국어.
- ⌥ теперь зарезервирован под перевод, поэтому его нельзя назначить в качестве
  модификатора основного хоткея.

### Загрузка языкового пакета

При первом переводе на новый язык macOS предлагает скачать языковую модель.
Приложение специально выводит на передний план небольшое окно «Подготовка языка
перевода» и активируется — иначе системный диалог загрузки не показался бы
menu-bar-приложению. После подтверждения загрузки перевод продолжается
автоматически, а окно закрывается. Дальше язык работает офлайн и мгновенно.

### Требования и деградация

- Перевод требует **macOS 15 или новее**. Само приложение по-прежнему работает
  на macOS 14 — там перевод отключён.
- Если язык или пара не поддерживается, показывается ошибка, а исходный русский
  текст остаётся в буфере обмена и в истории — ничего не теряется.

### Технические детали

- Публичный API Apple выдаёт `TranslationSession` только через SwiftUI
  `translationTask`, поэтому добавлен мост `AppleTranslationService`: скрытый
  `NSHostingView` в крошечном прозрачном окне, которое при необходимости
  становится видимым для диалога загрузки.
- Доступность пары проверяется через `LanguageAvailability().status(from:to:)`
  перед запуском сессии: `.unsupported` — сразу понятная ошибка,
  `.supported` — режим с окном загрузки, `.installed` — тихий быстрый перевод.
- Детектор ⌥ работает в глобальном polling-мониторе модификаторов, состояние
  фиксируется на момент отпускания — можно отпустить все три клавиши разом.
