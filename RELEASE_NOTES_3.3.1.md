## Главное

VoiceCapture 3.3.1 — критический фикс записи. В 3.3.0 после выбора микрофона распознавание могло не работать вообще: запись «шла», но аудио не захватывалось. Причина найдена и устранена — движок захвата переписан целиком.

## Что было сломано

Обнаружено две независимые проблемы в аудио-пути на `AVAudioEngine`:

1. **Смена устройства роняла аудио-граф.** `AVAudioEngine.inputNode` жёстко привязан к системному устройству ввода по умолчанию. Любая попытка переключить его завершалась ошибкой CoreAudio **-10868** (`AUGraphParser::InitializeActiveNodesInInputChain`) — движок не запускался. Проверены все известные обходные пути (современный `setDeviceID`, устаревший `AudioUnitSetProperty`, сброс графа, принудительная установка формата шины) — ни один не работает.

2. **Bluetooth-гарнитура ломала запись даже без выбора микрофона.** Когда системный вход — беспроводные наушники, macOS подставляет служебное агрегатное устройство `CADefaultDeviceAggregate-*`, которое не отдаёт ни одного аудио-буфера. Запись формально стартовала, но сэмплов было ноль.

## Что изменилось

- Захват звука переписан с `AVAudioEngine` на **`AVCaptureSession`** — единственный API macOS, который корректно работает с явно выбранным устройством ввода.
- Служебные агрегатные устройства macOS отфильтрованы: они не показываются в списке микрофонов и не используются как фолбэк.
- Ресемплинг в 16 kHz mono теперь делает сама система через `AVCaptureAudioDataOutput`, промежуточный конвертер удалён.
- Лимит авто-усиления тихого сигнала поднят с 20x до **60x**: встроенный микрофон MacBook отдаёт очень тихий поток, из-за чего нормальная речь ранее отбрасывалась фильтром тишины.
- Порог фильтра тишины снижен соответственно.
- В логи добавлена диагностика: счётчик полученных буферов и явные предупреждения — «устройство не отдало буферов» (проблема с доступом) либо «буферы есть, но сигнал пустой» (проблема с уровнем входа).

## Установка

1. Скачай и распакуй `VoiceCapture-3.3.1-macOS-arm64.zip`.
2. Перетащи `VoiceCapture.app` в `/Applications`, заменив предыдущую версию.
3. Если macOS блокирует запуск, сними карантин:

```bash
xattr -dr com.apple.quarantine /Applications/VoiceCapture.app
```

4. Запусти приложение. Существующие настройки и скачанные модели сохранятся.

## Требования

- Apple Silicon (M1 или новее);
- macOS 14 Sonoma или новее;
- разрешения Microphone и Accessibility.

## Приватность

FluidAudio / NVIDIA Parakeet TDT v3 работает локально через Core ML и Apple Neural Engine. Речь и live-транскрипт не отправляются в облако.
